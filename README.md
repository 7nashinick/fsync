# Fsync

Vault sync and sharing for Obsidian, backed by your own server. One dialog,
zero popups.

Fsync is a complete sync plugin built on the engine of
[Self-hosted LiveSync](https://github.com/vrtmrz/obsidian-livesync) (MIT),
with the entire setup and sharing experience redesigned around an account
server ([reference implementation](https://notes.foldoy.com)).

**Status: design.** The usage pipeline in
[docs/PIPELINE.md](docs/PIPELINE.md) is the contract; code follows it.
